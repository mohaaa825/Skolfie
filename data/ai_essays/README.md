# AI-written student essays (fresh source)

2,000 English student-style essays from current models, for retraining Skolfie on
today's AI text (`notebooks/retrain_modern.ipynb`). Fresh-source JSONL, gzipped.

| file | essays | role |
|---|---|---|
| `claude-opus-5-5.jsonl.gz` | 375 | train / val / test |
| `claude-sonnet-5-5.jsonl.gz` | 375 | train / val / test |
| `claude-haiku-5-5.jsonl.gz` | 250 | held out: unseen-model test only |
| `gemini-3.1-flash-lite.jsonl.gz` | 455 | train / val / test |
| `gemini-3.5-flash-lite.jsonl.gz` | 271 | train / val / test |
| `gemini-flash-lite-latest.jsonl.gz` | 242 | train / val / test |
| `gemini-3.5-flash`, `gemini-3.6-flash`, `gemini-3.7-flash` | 19 / 11 / 1 | train / val / test |

**Claude** (written 2026-10-29): prompts from
`skolfie.data.generation.student.student_prompt_plan(1000)`: 600 on the 15 PERSUADE 2.0
assignments (grade 6-12 personas, some asking the model to "sound like a real student") and
400 college essays and personal narratives. Made with `scripts/import_claude_essays.py`.

**Gemini** (generated by the project owner, 2026-10-30): 27 topics (school debates, lab
reports, Gatsby / Mockingbird / Macbeth essays, ...), 8 essay types, grades 6-12 and college,
150-600 words, many prompts asking to "sound less like AI". Made with
`scripts/import_csv_essays.py`, which strips Markdown and inline LaTeX (the human essays have
none) and groups the essays by topic and grade (as the Claude PERSUADE essays).

The retrain notebook uses these copies when `My Drive/skolfie/data/raw/fresh/` has no `.jsonl`
files.
